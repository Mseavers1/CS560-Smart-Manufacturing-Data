# SOP: Daily Startup

## Purpose
This SOP walks an operator through the minimum startup sequence for the Smart Manufacturing Research cell before a new session begins.

## Preconditions
- Confirm the work envelope is clear.
- Verify the emergency stop is released.
- Check that the robot controller, camera system, and data services have power.
- Review the latest maintenance notes before motion is enabled.

## Startup Sequence
- Open the dashboard and confirm the **Session Status** panel reads inactive.
- Verify camera and database links are available from the top navigation bar.
- Inspect pneumatic pressure, cable routing, and fixture alignment.
- Start a new session from the **Data Dashboard** once the area is safe.
- Watch the message panels for warnings during the first thirty seconds of operation.

## Operator Notes
- If communication fails, use the troubleshooting guide in this Info page before restarting devices.
- Keep session labels descriptive so later data review is easier.
- Record anything unusual in the daily log before handing the cell off to the next operator.
