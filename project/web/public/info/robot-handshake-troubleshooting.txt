ROBOT HANDSHAKE TROUBLESHOOTING
================================

Use this quick guide when the dashboard stops receiving expected camera or robot updates.

1. Confirm the active session has not been stopped by another operator.
2. Check network connectivity between the control PC and the robot subnet.
3. Re-open the camera and twins links from the top bar to verify both services respond.
4. Review the message panels for the first reported fault.
5. If the backend is online, query /session and /sessions from the API Explorer.
6. Restart only the affected service if the fault is isolated.
7. Escalate to engineering if the same handshake fault repeats three times in one shift.
